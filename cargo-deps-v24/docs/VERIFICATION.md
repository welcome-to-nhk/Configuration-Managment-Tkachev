# Протокол проверки

- Python unittest: **29 тестов, OK**.
- Проверены пять стадий через точку входа CLI.
- Проверено чтение Cargo JSONL через настоящий локальный HTTP-сервер.
- Проверены три опубликованных crate по сокращенному учебному срезу.
- Проверены цепь, ромб, общая зависимость, цикл, петля, лист, фильтрация.
- Проверены 404, DNS-ошибка, некорректные метаданные и параметры.
- Созданы девять пар .puml/.svg и журнал фактических запусков.
- SVG открыты в Chromium; изображения визуально проверены.
- Простой аудит: строки <=80, функции <=40, аргументы <=7,
  файлы <=1000; у функций есть docstring. Это не полный статический анализ
  и не доказательство соблюдения каждого правила методички.

- Online HTTP-запрос Python к crates.io: ошибка DNS.
- Настоящий Cargo tree: Cargo отсутствует. Готов скрипт для запуска у студента.
- Официальный PlantUML JAR: отсутствует. SVG сделаны собственным
  рендерером генерируемого подмножества PlantUML.
- Проверка запуска именно на Windows/macOS: команды предоставлены,
  но фактические проверки выполнялись в Linux.
- Публикация в публичный Git-сервис: нужна учетная запись студента.
