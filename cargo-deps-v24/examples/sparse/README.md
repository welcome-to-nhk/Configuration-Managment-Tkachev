# Автономный учебный срез sparse-индекса

Это сокращенные метаданные опубликованных версий, а НЕ полный индекс
и не точные побайтовые копии ответов. Не выдавайте их за онлайн-проверку.
Поля checksum/pubtime/MSRV удалены: анализатор не скачивает архивы.
Сохранены имена, ограничения, типы и optional-флаги зависимостей.

Источники, просмотрены при подготовке проекта:
- https://index.crates.io/cr/c3/crc32fast — 1.5.0
- https://index.crates.io/cf/g-/cfg-if — 1.0.4
- https://index.crates.io/mi/ni/miniz_oxide — 0.8.9
- https://index.crates.io/ad/le/adler2 — 2.0.1
- https://index.crates.io/it/oa/itoa — 1.0.15

В срезе для каждого crate одна версия. Поэтому «новейшая» здесь —
новейшая в этом маленьком срезе, а не в современном crates.io.
Срез достаточен для политики mandatory normal/build и демонстрации
на трех реальных пакетах. `tools/demo.py` раздает его по локальному HTTP.
Это НЕ режим `--test`: используется настоящий CargoRepository/JSONL/HTTP.
